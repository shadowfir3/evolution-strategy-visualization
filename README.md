# evolution-strategy-visualization

A small HTML and JavaScript visualization of an evolution strategy over a 2D sinus-based goodness function.

## Overview

This workspace contains a static browser visualization that renders:

- A `1600x800` canvas
- A grayscale background based on a 2D sinus goodness landscape
- A first generation of `50` randomly placed red dots
- A per-dot goodness score computed from the same sinus function

The current version is focused on the initial visualization layer: the landscape plus the first generation of candidate points.

## Workspace Structure

- `index.html`  
  Entry page for the workspace. It redirects to `main.html`.

- `main.html`  
  Main static HTML page containing the canvas and page layout.

- `style.css`  
  Visual styling for the page and canvas container.

- `script.js`  
  Canvas rendering logic, sinus goodness sampling, dot creation, and redraw loop.

- `LICENSE`  
  Project license.

## How It Works

The background image is generated by evaluating sinus values in the `x` and `y` directions for every canvas pixel. These values are shifted above zero, combined into a goodness value, and converted into a grayscale range from `0` to `255`.

After the background is created, the script generates `50` random dots across the canvas. Each dot stores:

- `x` coordinate
- `y` coordinate
- `goodness` value

These dots are drawn as red circles on top of the grayscale landscape.

## Local Test

You can run the workspace as a local static web server and test it directly in a browser.

### Start a Local Server

From the workspace root, run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

This serves `index.html`, which redirects to `main.html`.

## Notes for Codespaces / Remote IDEs

If you are using GitHub Codespaces or another remote development environment, `localhost` may need to be opened through a forwarded port.

Use port:

```text
8000
```

Then open the forwarded URL from the IDE's `Ports` panel.
